# 镜像输出示例

广播页打开后，把同 tab 的其他窗格并排成多个分格镜像。每个分格：

- 实时镜像目标窗格的可见输出（保留原始终端样式：前景/背景/加粗/反显等）
- 一个反显空格渲染的块状影子光标（图中用 `█` 代表），落在镜像最后一行非空内容之后——下一个广播字符会落到这里
- 分格之间用 1 列 dim 分隔线相隔，无边框

例如两个目标（helix + opencode）：

```
 hello.txt  12 lines  [NORMAL]█   │  > fix the bug in line 42...█
```

输入字符时光标同步前进；按 Enter 后目标各自的输出展开到镜像里；目标关闭后会变红字 `✕ dead`；全部失效时自动退出。
